# 🚁 YOLOv8 Drone & Object Detection

Real-time object detection on images and videos using YOLOv8 on Google Colab.

## ✨ Features
- Object detection on images
- Object detection on videos with result saving
- Support for custom models (e.g. best_sky.pt)
- Runs directly on Google Colab — no setup needed

## 🚀 How to Run
[

![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)

](https://colab.research.google.com/github/xxmadara1xx/yolov8-drone-detection/blob/main/test_yolov8.ipynb)

1. Click the button above
2. Run the cells in order
3. Upload your images or videos to Google Drive

## 📦 Models
- **yolov8x.pt** — downloaded automatically
- **best_sky.pt** — custom model, place it in Google Drive

## 🛠️ Requirements
ultralytics, opencv-python
(installed automatically in the first cell)
